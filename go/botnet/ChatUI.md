## Layout

Two panes:

- **Left nav** — the bot list.
  - What each row shows: displayName, model? last message preview? unread?
  - Actions from the nav: new bot, ...
- **Right panel** — the conversation with the selected bot.
  - Message stream (user right / bot left? timestamps?)
  - Composer at the bottom
  - Where does the bot's config live (systemPrompt, model picker) — header
    dropdown? side sheet? separate view?
